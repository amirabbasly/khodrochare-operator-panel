# 🚗 پنل CRM امداد خودرو سراسری (Khodrochare Operator Panel)

سامانه‌ی مدیریت درخواست‌های امداد خودرو برای اپراتورهای پاسخگو و مدیر شرکت؛ با داشبورد آماری،
ثبت و پیگیری بارها، مدیریت امدادگران و مدیریت کامل حساب‌های اپراتور.

**تکنولوژی:** Next.js 16 (App Router) · React 19 · Node.js/Express · PostgreSQL 16 · Docker

---

## ✨ امکانات

### صفحه ورود
- انتخاب نوع دسترسی در همان صفحه: **مدیر** یا **اپراتور**
- ورود با نام کاربری و رمز عبور (JWT + bcrypt با ۱۲ دور هش)
- **هیچ رمز واقعی روی صفحه‌ی ورود نمایش داده نمی‌شود** (فقط «حساب تله» برای شناسایی مهاجم)
- **تله‌ی امنیتی:** هر کسی با حساب ادمین فیک وارد شود، IP او مسدود و در پنل ثبت می‌شود
- پیام خطای یکسان برای همه‌ی حالت‌های شکست (ضد افشای وجود حساب)
- قفل موقت حساب پس از ۵ تلاش ناموفق + محدودیت نرخ بر اساس IP
- جلوگیری از ورود با نقش اشتباه و ورود به حساب غیرفعال

### پنل اپراتور
| بخش | توضیح |
| --- | --- |
| **داشبورد** | آمار کلی: کل بارها، تایید/کنسل/در انتظار، شهرها و محدوده‌های پرتقاضا، امدادگران با بیشترین تایید و بیشترین کنسلی، روند روزانه، دلایل کنسلی و پرتکرارترین مشکلات خودرو |
| **بارها** | ثبت بار با اطلاعات امدادخواه (نام خودرو، شماره تماس، مشکل خودرو، نام امدادخواه، نام امدادگر، آدرس، توضیحات) + دکمه‌های **تایید / کنسل** (قابل ویرایش) + **پیگیری انجام شد / نشد** + فیلتر تاریخ شمسی + بستن روزانه + جست‌وجو + خروجی CSV |
| **پیگیری‌ها** | دو صفحه‌ی مستقل `/follow-ups/done` و `/follow-ups/not_done` با اطلاعات کامل هر بار، جست‌وجو، فیلتر تاریخ و تغییر وضعیت پیگیری |
| **امدادگران** | ثبت و ویرایش امدادگر: نام و نام خانوادگی، خودرو، پلاک، **محدوده و شهر (تایپ آزاد اپراتور، بدون انتخاب از فهرست)**، نوع کار (**حملی / تعمیر در محل / هر دو / تعمیرگاهی ⭐ امتیاز ویژه**) + جست‌وجوی هوشمند (مثلاً `محمودآباد` یا `امیرکریمی`) |
| **مالی هر بار** | مبلغ دریافت‌شده از امدادخواه (با کاما)، نوع بار (حملی / تعمیر در محل / امکان اعزام به تعمیرگاه)، محاسبه‌ی خودکار سهم خودرو چاره (۲۰٪ / ۳۰٪) و نمایش سهم امدادگر، وضعیت اعزام به تعمیرگاه و دکمه‌ی «پرداخت شد / نشد» |
| **حساب من** | مشاهده‌ی اطلاعات حساب (فقط خواندن؛ تغییر نام/شماره/کد ملی و رمز عبور فقط توسط مدیر) |

### پنل مدیر
- **مدیریت اپراتورها:** ساخت اپراتور جدید (نام، نام خانوادگی، نام کاربری، رمز عبور، شماره تماس، کد ملی)، ویرایش، **تغییر رمز (با بسته‌شدن همه‌ی نشست‌های قبلی اپراتور)**، رفع قفل حساب، فعال/غیرفعال‌سازی، حذف
- **دسترسی کامل:** فقط مدیر می‌تواند رمز عبور و اطلاعات حساب‌ها را تغییر دهد یا حسابی را حذف کند
- **💰 تب مالی گزارش‌ها:** مبلغ کل دریافتی، سهم امدادگران، پرداخت‌شده، مانده، تفکیک بر اساس نوع بار و امدادگران با بیشترین بدهی
- **🛡️ بخش امنیت:** فهرست IPهای مسدودشده با دلیل، نام کاربری تلاش‌شده، تعداد تلاش، زمان و مرورگر + رفع مسدودی و مسدودسازی دستی
- **گزارش‌های کامل:** آمار تفصیلی بارها، شهرها و محدوده‌ها، امدادگران، عملکرد اپراتورها، دلایل کنسلی، مشکلات خودرو، روند روزانه/ماهانه، بازه‌ی تاریخ دلخواه، چاپ و خروجی CSV
- دسترسی کامل به بخش‌های بارها و امدادگران

### قابلیت‌های عمومی
- رابط کاربری **فارسی و راست‌به‌چپ** با فونت وزیرمتن و **تاریخ شمسی همراه با ساعت** (ورودی تاریخ شمسی مثل `۱۴۰۴/۰۸/۱۳` و نمایش تاریخ + ساعت در جدول‌ها)
- **جست‌وجوی بدون حساسیت به فاصله/نیم‌فاصله** (جست‌وجوی «امیرکریمی» نام «امیر کریمی» را پیدا می‌کند)
- **بستن روزانه:** هر روز پس از پایان کار بسته می‌شود و از ویرایش داده‌های آن روز جلوگیری می‌شود (با امکان بازگشایی)
- صفحه‌بندی، اعتبارسنجی سمت سرور و کلاینت، پیام‌های خطای فارسی، لاگ درخواست‌ها
- طراحی واکنش‌گرا (موبایل، تبلت، دسکتاپ)

## 🚀 اجرای سریع با Docker (پیشنهادی)

```bash
# 1) کپی تنظیمات
cp .env.example .env
nano .env                     # JWT_SECRET و رمزها را تغییر دهید

# 2) ساخت و اجرا
docker compose up -d --build

# 3) (اختیاری) داده‌ی نمونه برای تست
docker compose exec api node src/db/seed.js
```

سپس:
- پنل: <http://localhost:3000>
- API: <http://localhost:4000/api/health>

### حساب‌های پیش‌فرض

| نقش | نام کاربری | رمز عبور |
| --- | --- | --- |
| مدیر | `admin` (یا مقدار `ADMIN_USERNAME`) | `admin12345` (یا مقدار `ADMIN_PASSWORD`) |
| اپراتور (فقط پس از seed) | `ali.rezaei` | `operator12345` |

> ⚠️ بلافاصله پس از نصب، رمز مدیر را از داخل پنل تغییر دهید.

## 💻 اجرای محلی بدون Docker

پیش‌نیاز: Node.js 20+ و PostgreSQL 14+

```bash
# نصب وابستگی‌ها
npm install

# ساخت دیتابیس
sudo -u postgres psql -c "CREATE USER khodrochare WITH PASSWORD 'khodrochare';"
sudo -u postgres psql -c "CREATE DATABASE khodrochare_crm OWNER khodrochare;"

# تنظیمات محیطی
cp .env.example .env          # DATABASE_URL یا DB_* را تنظیم کنید
export $(grep -v '^#' .env | xargs)

# ساخت جداول + حساب مدیر
npm run migrate

# (اختیاری) داده‌ی نمونه
npm run seed

# اجرای همزمان API و وب
npm run dev
```

- وب: <http://localhost:3000>
- API: <http://localhost:4000/api>

### حالت دمو بدون PostgreSQL

برای نمایش سریع بدون نصب دیتابیس (داده در حافظه، فقط برای تست):

```bash
npm run demo --workspace backend       # API روی پورت ۴۰۰۰ با داده‌ی نمونه
API_PROXY_TARGET=http://localhost:4000 npm run dev --workspace frontend
```

## ⚙️ متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `PORT` | `4000` | پورت API |
| `DATABASE_URL` | — | رشته اتصال PostgreSQL (جایگزین `DB_*`) |
| `DB_HOST` / `DB_PORT` / `DB_USER` / `DB_PASSWORD` / `DB_NAME` | `localhost` / `5432` / `khodrochare` / … | تنظیمات اتصال |
| `DB_SSL` | `false` | فعال‌سازی SSL برای دیتابیس ابری |
| `JWT_SECRET` | — (**الزامی در production**) | کلید امضای توکن |
| `JWT_EXPIRES_IN` | `12h` | مدت اعتبار توکن |
| `APP_TIMEZONE` | `Asia/Tehran` | مبنای «امروز» برای بارها و بستن روز |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | `admin` / `admin12345` | مدیر اولیه هنگام اولین مهاجرت |
| `AUTO_SEED` | `false` | ساخت خودکار داده‌ی نمونه |
| `CORS_ORIGINS` | خالی (همه) | دامنه‌های مجاز با کاما |
| `API_PROXY_TARGET` | `http://127.0.0.1:4000` | آدرس API برای پروکسی Next.js |
| `NEXT_PUBLIC_SHOW_DEMO_ACCOUNTS` | `true` | نمایش حساب‌های نمایشی در صفحه ورود |

## 🔌 خلاصه‌ی API

همه‌ی مسیرها زیر `/api` هستند و به‌جز `/auth/login` و `/health` نیاز به هدر
`Authorization: Bearer <token>` دارند.

| متد | مسیر | دسترسی | توضیح |
| --- | --- | --- | --- |
| POST | `/auth/login` | عمومی | ورود (نام کاربری، رمز، نقش اختیاری) |
| GET | `/auth/me` | همه | اطلاعات کاربر جاری |
| POST | `/auth/change-password` | همه | تغییر رمز خود |
| GET/POST | `/loads` | همه | فهرست (فیلتر تاریخ/وضعیت/شهر/جست‌وجو) و ثبت بار |
| GET/PATCH/DELETE | `/loads/:id` | همه (حذف: مدیر) | جزئیات، ویرایش، حذف |
| PATCH | `/loads/:id/status` | همه | تایید / کنسل (با دلیل کنسلی) |
| PATCH | `/loads/:id/follow-up` | همه | پیگیری انجام شد / نشد |
| GET | `/loads/export` | همه | خروجی CSV |
| GET/POST | `/rescuers` | همه | فهرست و ثبت امدادگر |
| GET/PATCH/DELETE | `/rescuers/:id` | همه (حذف: مدیر) | جزئیات و ویرایش |
| GET/POST | `/users` | مدیر | فهرست و ساخت اپراتور |
| PATCH/DELETE | `/users/:id` | مدیر | ویرایش/حذف کاربر |
| PATCH | `/users/:id/password` | مدیر | تغییر رمز کاربر |
| GET | `/stats/overview` | همه | آمار کلی بازه |
| GET | `/stats/detailed` | مدیر | آمار تفصیلی + عملکرد اپراتورها |
| GET | `/stats/operators` | مدیر | آمار اپراتورها |
| GET | `/stats/today` | همه | آمار یک روز |
| GET | `/days` , `/days/:date` | همه | فهرست و وضعیت روزها |
| POST | `/days/:date/close` , `/days/:date/reopen` | همه | بستن/بازگشایی روز |
| GET | `/meta/zones` | همه | محدوده‌ها و شهرها |
| GET | `/meta/lookups` | همه | وضعیت‌ها، نوع کارها، دلایل کنسلی |
| GET | `/health` | عمومی | سلامت سرویس |

## 🔐 نکات امنیتی

- `JWT_SECRET` را حتماً مقدار تصادفی طولانی بگذارید: `openssl rand -hex 32`
- رمز پیش‌فرض مدیر را تغییر دهید و اپراتورها را با رمز قوی بسازید
- پورت دیتابیس را روی اینترنت باز نکنید (در compose فقط داخل شبکه است)
- از پنل پشتیبان‌گیری دوره‌ای بگیرید (روش `pg_dump` در DEPLOY.md)
- در صورت استفاده از HTTPS، دسترسی مستقیم به پورت ۴۰۰۰ را ببندید و همه‌چیز را از Nginx عبور دهید
